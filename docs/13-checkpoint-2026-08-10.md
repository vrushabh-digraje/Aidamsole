## Architecture

```
Browser
  → Next.js App Router (pages + UI)
    → API routes (/api/contact, /api/assessment)
      → Zoho CRM / email / DB helpers (server-side)
```

| Layer | Responsibility | Key paths |
|--------|----------------|-----------|
| Pages | Routes & SEO metadata | `app/` |
| Templates | Industry / Solution / Platform layouts | `components/{industries,solutions,platform}/` |
| Sections | Homepage & reusable blocks | `components/sections/` |
| Layout chrome | Header, footer, nav, logo | `components/layout/` |
| UI atoms | Button, Card, icons, badges | `components/ui/` |
| SEO | JSON-LD, metadata helpers | `components/seo/`, `lib/seo.ts` |
| Content data | Page copy by slug | `lib/data/`, `lib/insights.ts` |
| Publish gate | Nav + sitemap allowlist | `lib/published.ts` |
| Nav source | Mega menu + footer | `lib/navigation.ts` |
| Site constants | NAP, phones, CTAs, routes | `lib/constants.ts` |

**Rule:** Nav, footer, and sitemap only show **published** entries from `lib/published.ts`.

## Publish control (SSOT)

| Consumer | Gate |
|----------|------|
| Nav / footer | `getPublishedSolutions/Industries/Platforms` via `lib/navigation.ts` |
| Homepage + hubs + teasers | `getPublished*` |
| Detail pages | `isPublished*(slug)` → else `notFound()` |
| Sitemap | `getPublishedSitemapEntries()` |

To unpublish: remove slug from `PUBLISHED` in `lib/published.ts` (do not rely on data flags alone).
