# 05 — User Flow

## Journey Overview

Primary visitor: CEO or Ops Head from a 50–500 person company in India / GCC, evaluating Zoho help after process pain or a weak prior implementation.

```
Landing → Trust building → Exploration → Conversion (Talk to Expert)
```

Not every visitor completes all stages. The product job is to move serious buyers forward without forcing a demo theater path.

## Stage 1 — Landing

### Entry points

| Source | Likely landing surface |
| --- | --- |
| Brand / direct | Homepage Hero |
| Referral / sales link | Homepage or Contact |
| Industry search | Industries module or `/industries/[slug]` |
| Problem search | Insights article or Capabilities |

### Visitor questions at entry

- Is this a serious Zoho partner or another agency site?
- Do they work with companies like mine?
- Can I talk to someone who understands operations, not only CRM fields?

### Success criteria

- Positioning is clear in the first screen: enterprise Zoho consulting, system design, not tool selling
- Primary action visible: Talk to Expert
- Secondary path available: scroll to Capabilities / Industries

### Drop-off causes

- Looks like a generic IT or marketing agency
- Unclear who the offer is for
- CTA buried or overselling

## Stage 2 — Trust Building

### What the visitor does

Scans proof that AiDamsole can be trusted with process and systems work.

### Surfaces used

1. **Hero** — who we serve and what we own
2. **Capabilities** — CRM + operations transformation, not module checklists
3. **Approach** — how engagement works; signals discipline and partnership
4. **Social proof later** (when available) — case outcomes, industry examples, leadership language

### Trust checks

| Check | Pass signal |
| --- | --- |
| Authority | Speaks in operating outcomes, not feature lists |
| Relevance | Mentions decision makers and company scale |
| Risk reduction | Approach shows diagnosis before configuration |
| Continuity | Implies post go-live ownership |

### Success criteria

- Visitor believes this is a consulting partner, not a setup vendor
- Enough confidence to explore industries or continue to CTA

### Drop-off causes

- Buzzword-heavy copy
- No clear method
- No industry recognition

## Stage 3 — Exploration

### What the visitor does

Looks for fit: industry, Zoho situation, and whether the engagement model matches their risk.

### Paths

| Path | Intent |
| --- | --- |
| Industries | “Have they done work like ours?” |
| Approach | “How invasive / structured is this?” |
| Insights | “Do they understand the problem deeply?” |
| Capabilities detail | “Is this CRM-only or full ops?” |

### Realistic behavior

- Skims, does not read every section
- Compares mentally with previous Zoho partner
- May leave and return via Insights or direct later
- High-intent visitors jump to Talk to Expert after one trust pass

### Success criteria

- Visitor can self-qualify: industry fit, company type, engagement expectation
- Friction stays low: no mandatory account, no longgate before contact

### Drop-off causes

- Too many pages before a clear ask
- Industry pages that only list Zoho products
- Content written for developers, not operators

## Stage 4 — Conversion (Talk to Expert)

### Trigger moments

- Nav CTA clicked after skimming
- Hero CTA for already-convinced referral traffic
- End of Approach / Industries when fit feels confirmed
- Insights article CTA after problem recognition

### Conversion action

Visitor chooses **Talk to Expert** and submits a short structured enquiry (or starts contact flow).

Minimum intent data:

- Name, work email, company
- Role, industry, region
- Zoho status + need summary

### Immediate system response

1. Confirm submission on site
2. Create / update lead in Zoho CRM
3. Assign owner
4. Sales follows up (SLA owned in CRM)

### Success criteria

- Submit completes without confusion
- Visitor knows what happens next (e.g. expert will respond)
- Lead arrives in Zoho with source and context

### Drop-off causes

- Form asks for too much too early
- No confirmation state
- Fear of spam / junior sales call (positioning must stay expert-level)

## End-to-End Flow Map

```
[Land]
  Hero / Industry / Insight
        │
        ▼
[Trust]
  Capabilities + Approach
        │
        ├── low intent → leave / return via Insights
        │
        ▼
[Explore]
  Industries · Approach detail · Insights
        │
        ├── not a fit → exit
        │
        ▼
[Convert]
  Talk to Expert
        │
        ▼
  Lead capture → Zoho CRM → Sales ownership → Discovery call
```

## Branching Notes

| Visitor type | Likely path |
| --- | --- |
| Referred by peer | Land → short trust scan → Talk to Expert |
| Burned by prior partner | Land → Approach → Capabilities → Talk to Expert |
| Industry researcher | Insight/Industry → Approach → Talk to Expert |
| Early browser | Land → skim → leave → return later |

## Flow Rules

1. Talk to Expert is always available after first paint (nav).
2. Trust before depth — do not force long exploration to convert.
3. Exploration exists to qualify and reduce risk, not to delay the CTA.
4. Every conversion path ends in Zoho, not inbox-only handling.
