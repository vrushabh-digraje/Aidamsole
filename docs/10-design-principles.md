# 10 — Design Principles

## Direction

Consulting-firm UI. Closer to Deloitte / Accenture than startup SaaS.

The interface should feel calm, senior, and credible — built for CEOs and Ops Heads.

## Principles

### 1. Minimal

- Few elements per section
- No decorative chrome, gradients-as-decoration, or icon grids for show
- One idea per block

### 2. Typography-driven

- Hierarchy carries the page: headline → support → action
- Strong, readable type over illustration-led layouts
- Copy is the primary visual material

### 3. High whitespace

- Generous spacing between sections
- Let content breathe; avoid dense marketing stacks
- White / near-white grounds preferred

### 4. Authority-first

- Restrained color, clear structure, confident language
- Signal expertise before personality
- CTAs are clear, not loud

### 5. No flashy UI

- No heavy animation, glow, glass, or novelty components
- Motion only when it aids orientation
- Prefer static clarity over interactive spectacle

## Design Do / Don’t

| Do | Don’t |
| --- | --- |
| Quiet layout, sharp type | Card spam and badge clutter |
| Enterprise restraint | Startup “playful” patterns |
| Clear Talk to Expert CTA | Multiple competing asks |
| Long-form trust sections | Feature fireworks |

## North Star

If the page feels like a serious advisory firm, it is on-brand.  
If it feels like a product launch page, simplify.
